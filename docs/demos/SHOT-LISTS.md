## Recording Tips

1. **Browser**: Chrome, dark mode, 1920x1080
2. **Tool**: OBS or Loom
3. **URL bar**: Show `app.sip-protocol.org` prominently
4. **Mouse**: Slow, deliberate movements. Pause on important elements.
5. **Zoom**: Use browser zoom (Cmd++) on commitment hashes and stealth addresses
6. **Wallet**: Connect Phantom in demo mode before recording
7. **Timing**: Practice the flow 2x before recording — 75 seconds goes fast
